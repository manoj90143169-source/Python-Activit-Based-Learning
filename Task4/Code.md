# Employee Payroll and Deduction Analysis Using Python

## 1. Problem Statement

Develop a Python program to calculate employee gross salary using basic pay, allowances, overtime, and incentives. Apply progressive deductions and generate a formatted salary statement showing gross salary, deductions, and net salary.

## 2. Algorithm

1. Start the program.
2. Enter employee details and salary components.
3. Calculate gross salary.
4. Apply progressive deductions.
5. Calculate net salary.
6. Display the salary statement.
7. Stop.

## 3. Flowchart
``` mermaid

flowchart TD
 A([Start]) --> B[/Enter salary details/]
 B --> C[Calculate gross salary]
 C --> D[Calculate progressive deductions]
 D --> E[Calculate net salary]
 E --> F[/Display salary statement/]
 F --> G([Stop])
```

## 5. Sample Input

Enter employee name: Ravi
Enter basic pay: 25000
Enter allowances: 5000
Enter overtime pay: 2000
Enter incentives: 3000

## 6. Sample Output

--- Salary Statement ---
Employee: Ravi
Gross Salary: Rs. 35000.0
Deduction: Rs. 2500.0
Net Salary: Rs. 32500.0
