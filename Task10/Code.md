# Campus Event Financial Planning Using Python

## 1. Problem Statement

Develop a Python program to calculate campus event expenses, including venue, equipment, catering, transport, and certificates. Calculate participant contributions, sponsorship shortfalls, and minimum registrations required to break even.

## 2. Algorithm

1. Start the program.
2. Enter all event expenses.
3. Calculate total cost.
4. Enter sponsorship and registration fee.
5. Calculate sponsorship shortfall.
6. Calculate participant contribution.
7. Find minimum registrations required.
8. Display the financial report.
9. Stop.

 G --> H([Stop])

## 5. Sample Input
Enter venue cost: 10000
Enter equipment cost: 5000
Enter catering cost: 20000
Enter transport cost: 5000
Enter certificate cost: 2000
Enter sponsorship amount: 12000
Enter registration fee per person: 300
Enter expected participants: 100

## 6. Sample Output
--- Event Financial Report ---
Total Cost: Rs. 42000.0
Sponsorship Shortfall: Rs. 30000.0
Contribution per Participant: Rs. 300.0
Minimum Registrations: 100
